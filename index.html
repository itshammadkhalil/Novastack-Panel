    One setting to keep on

    Client accounts are linked to their project by email address. In Supabase, keep Authentication → Sign In / Providers → Confirm email switched on, so nobody can register a client's email address before the client does and claim their project view.

    Password recovery (forgot password)

    Any user — client or founder — who forgets their password uses Forgot password? on the sign-in screen. Supabase Auth emails a single-use, short-lived reset link; opening it lands on this dashboard's Set a new password screen, where the user chooses a new password with updateUser. No password is ever stored or seen by NovaStack, and this page never handles the old password. For the email link to land here, keep Supabase Authentication → URL Configuration → Site URL set to https://dashboard.novastackltd.com/ and that same URL in Redirect URLs (both already set). If a client says the link expired, tell them to request a fresh one — old links cannot be reused.

    PKR and USDT projects

    When you add a client or create a project, choose PKR for local clients or USDT for international clients. The whole project — value, paid, remaining and every payment row — is then shown in that currency, and the founder stats keep PKR and USDT totals separate (they are never added together or converted). Payment methods now include USDT (TRC20) and USDT (ERC20) alongside bank transfer, JazzCash and EasyPaisa. You can also switch an existing project's currency in Project settings — do it before recording payments, because amounts are not converted automatically.

    Production settings outside this page

    Login sessions, token signing, expiry and refresh rotation are handled by Supabase Auth, and this page sets no cookies of its own; keep the default session settings in Supabase Authentication as they are. On Hostinger, keep HTTPS forced on for this subdomain; response headers such as Strict-Transport-Security and X-Content-Type-Options are sent by the host, not by this file, so check them there. In the GitHub repo, turn on Dependabot alerts and secret scanning with push protection (Settings, Code security) so a vulnerable library version or a leaked key is flagged automatically. The sign-in library on this page is pinned to one exact version, so it can never change silently; update it deliberately, one version at a time.
