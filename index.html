    Notes & settings to keep

    Confirm email — keep on

    Client accounts link to their project by email. In Supabase keep Authentication → Sign In / Providers → Confirm email on, so nobody can register a client's email first and claim their project view.

    Password recovery

    Users reset via Forgot password? on the sign-in screen; Supabase emails a single-use, short-lived link that lands on this dashboard's Set a new password screen. Keep the Supabase Site URL and Redirect URLs set to https://dashboard.novastackltd.com/ (already set). Expired links cannot be reused — the client should request a fresh one.

    PKR and USDT projects

    Choose PKR for local clients or USDT for international clients when adding a client or creating a project. The whole project is shown in that currency, and founder stats keep PKR and USDT totals separate — never added together or converted. Currency can be switched in Project settings, before recording payments.

    Production settings outside this page

    Sessions, token signing, expiry and refresh rotation are handled by Supabase Auth; this page sets no cookies. On Hostinger keep HTTPS forced on; security headers are sent by the host. In GitHub, keep Dependabot alerts and secret scanning with push protection on. The sign-in library is pinned to one exact version and only updated deliberately.
